# 🤖 ITIANS Career Assistant - Professional Guidance

## 📋 Overview
The ITIANS Career Assistant has been developed using Firebase and Gemini AI to provide professional career guidance and support for ITI graduates. The assistant is specifically designed to help users maximize their professional potential on the ITIANS platform and advance their careers in the tech industry.

## 🚀 How to Use

### Floating Chat Widget
1. Click the floating button in the bottom-right corner
2. Type your message or choose from suggestions
3. Get an instant response from the assistant
4. Click the "Open Full Page" icon to go to the full chatbot page

### Full Chatbot Page
1. Navigate to `/chatbot`
2. Browse previous conversations in the sidebar
3. Search conversations using the search bar
4. Add conversations to favorites or delete them
5. Create new conversations
